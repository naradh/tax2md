🧾 tax2md

Turn a ClearTax computation report into clean Markdown for AI.

What this is for: ClearTax computation reports only. In your browser, save the report page as “Webpage, Complete” (a .html file), then drop it below. You get clean Markdown to paste into Claude, ChatGPT, etc. — typically 80%+ fewer tokens than feeding the raw HTML.
100% in your browser. Your file is never uploaded — this page has no server.
